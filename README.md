# Basil Voxel
An asset baker and decoder for voxel worlds. It is a multi folder structured volumetric storage file format that is compatible with the worlds generated by the basil minimal engine.
## File structure
The main entry point for any Basil world is the manifest.toml. This contains all of the metadata necesarry to compile a large world into engine consumable meshes. It contains metadata about the tool usage, along with a binary map of indexed region binary files containing the encoded volumetric information.
The main sauce of the file is the binary **.bvr, which stands for binary voxel region file. Any file with this extension can be loaded standalone as an asset in the engine, but what puts all of these toghether is the manifest on the root of the directory.
Textures and voxel data are stored in **.btx, or basil texel files, which are referenced in the **.btx files if in the same directory, or anywhere in the asset file if there is a manifest.toml sitting at the root of the directory of the file structure
